## &nbsp;The throughline

Student and builder in Naperville, IL, working across software, hardware, and research.
What I'm really chasing lives where engineering meets the physical world: **cars that
think at 200 mph, and sensors that read the human body without a needle.**

Those sound unrelated, but to me they're the same problem — *take a noisy, complex
system and pull a clean signal out of it, in real time.*

<br/>
